# Catalogue d'erreurs kubectl

Chaque fichier `*.yaml` de ce répertoire regroupe les erreurs d'une catégorie (`cmdline`,
`connection`, `auth`…). Le contenu pédagogique est rédigé **en français**.

Le format (data-model.md § CatalogEntry) et les règles de validation sont vérifiés par
`internal/catalog/catalog_test.go` et `internal/catalog/safety_test.go`.
